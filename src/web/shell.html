TableMD Help

Getting Started

TableMD is a visual markdown table editor. Click anywhere on the canvas to start creating your first table.

Basic Controls

  • Click - Select and edit a cell
  • Tab - Navigate between cells
  • Enter - Move to next row
  • Drag - Pan around the canvas
  • Pinch or (Ctrl + Scroll) - Zoom in and out

Editing Tables

  • Type in any cell to add content
  • Edit cells adjacent to the table to expand it
  • Use Ctrl + V or ⌘ + V to paste text
  • Tables automatically save as you work

Export Options

Use the panel on the right to:

  • Copy markdown source code
  • Copy rendered HTML
  • Clear all tables if needed

Tips

  • Your work is automatically saved locally
  • Works offline once loaded
  • Optimized for both desktop and mobile
